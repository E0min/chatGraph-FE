# 테스트 가이드 (Test Guide)

<!-- 담당 에이전트: frontend, backend -->

## 1. 테스트 전략 개요
- **철학**: 빠른 피드백 + 높은 신뢰도
- **자동화 수준**: CI 파이프라인 내 자동 실행

## 2. 테스트 피라미드
```
    ┌──────┐
    │ E2E  │  ← 적게, 핵심 플로우만
    ├──────┤
    │ 통합  │  ← 모듈 간 연동 검증
    ├──────┤
    │ 단위  │  ← 많이, 빠르게
    └──────┘
```

## 3. 단위 테스트
- **대상**: 유틸 함수, 커스텀 훅, 서비스 로직
- **도구**: Jest / Vitest
- **네이밍**: `describe('[대상]') → it('[조건]일 때 [결과]')`
- **Mocking**: 외부 의존성만 최소한으로 Mock
- **커버리지 기준**: 비즈니스 로직 80% 이상

## 4. 통합 테스트
- **대상**: API 엔드포인트, DB 연동, 컴포넌트 인터랙션
- **도구**: Testing Library, Supertest
- **DB**: 테스트 전용 DB 또는 인메모리 DB
- **정리**: 각 테스트 후 데이터 롤백

## 5. E2E 테스트
- **대상**: 핵심 유저 플로우 (로그인, 결제 등)
- **도구**: Playwright / Cypress
- **환경**: Staging 환경에서 실행
- **시나리오**: PRD의 수용 기준 기반

## 6. 테스트 데이터 관리
- **Fixture**: `/tests/fixtures/`에 JSON 형태로 관리
- **Factory**: 동적 테스트 데이터 생성 패턴 사용
- **시드 데이터**: 개발/테스트 환경 초기 데이터

## 7. CI 연동
- PR 생성 시 자동 실행
- 실패 시 머지 차단
- 커버리지 리포트 자동 생성
