## 2. 수평 확장 전략
- **로드밸런싱**: Round Robin / Least Connections
- **Auto-scaling**: 트리거 조건 (CPU > 70%, Memory > 80%)
- **Stateless 설계**: 세션은 외부 저장소 (Redis)

## 3. 캐싱 전략
| 레이어 | 도구 | 대상 | TTL |
|--------|------|------|-----|
| CDN | | 정적 자산 | 1일 |
| Application | Redis | 세션, 빈번 쿼리 | 쿼리별 설정 |
| Browser | Cache-Control | 정적 파일 | 1년 |

## 4. 비동기 처리
- **Message Queue**: (Bull / RabbitMQ / SQS)
- **대상 작업**: 이메일, 알림, 리포트 생성 등
- **재시도 정책**: 최대 3회, 지수 백오프

## 5. DB 확장
- **Read Replica**: 읽기 부하 분산
- **Connection Pooling**: 최대 연결 수 관리
- **인덱스 최적화**: 슬로우 쿼리 모니터링

## 6. 비용 최적화
