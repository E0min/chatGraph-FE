## 2. 서버 아키텍처 (레이어 구조)

### 2.1. Controller Layer
- HTTP 요청/응답 처리
- 입력 검증 (DTO 변환)
- 라우팅

### 2.2. Service Layer (비즈니스 로직)
- 핵심 비즈니스 규칙 구현
- 트랜잭션 관리
- 외부 서비스 조율

### 2.3. Repository Layer (데이터 접근)
- DB CRUD 연산
- 쿼리 최적화
- 데이터 매핑

| 미들웨어 | 설명 | 순서 |
