# UI/UX 가이드라인

## 1. 개요
`chatGraph-FE-local`의 핵심 특성은 **방대한 그래프 화면과 채팅 상호작용**이 동시에 일어나는 것입니다. 따라서 화면 크기에 구애받지 않는 반응성과 동적 레이아웃이 최우선 고려 대상입니다.

## 2. 레이아웃 가이드 (Layout Guide)

### 모바일 환경 (Mobile)
- 한정된 픽셀로 인해 **채팅 뷰(Linear Chat)가 기본 뷰**로 노출됩니다.
- 그래프 뷰는 전체 화면 모달 형태나, 탭 구조로 전환하여 제공합니다.

### 데스크탑 환경 (Desktop)
- Split View (분할 화면) 방식 지원 권장. (좌: 채팅 목록 탐색 / 우: 그래프 시각화)
- 그래프 확대 축소 시 Pan/Zoom 제어에 따른 사이드바 또는 채팅 패널 오버랩(Overlay) 혹은 밀어내기(Push) 옵션 준수.

## 3. 타이포그래피 (Typography)
- 정보 계층(Hierarchy)이 분명해야 합니다. 본문과 제목 사이 여백, 컨텍스트 스레드 사이 여백은 디자인 시스템(Tailwind spacing `.space-y-4`)에 의존.
- D3 라벨 텍스트 가독성을 위해 노드 내 텍스트는 그림자 처리를 권장.

## 4. 인터랙션 및 애니메이션 (Interaction)
- **모달 애니메이션**: 투명도, 작게/크게 페이드 효과 (Tailwind `ease-out`, `duration-200`)
- **생성 로딩**: 사용자가 새 토픽을 질문할 때 대기 상태는 UI 멈춤 없이 낙관적 업데이트로 처리하되, `Spinning Indicator`를 우측 하단에 조용히 띄웁니다.
- `tw-animate-css` 지원 유틸 활용.
