# 반응형 명세 (Responsive Spec)

<!-- 담당 에이전트: designer -->

## 1. 브레이크포인트 정의
| 이름 | 범위 | 대상 기기 |
|------|------|----------|
| Mobile | 0 ~ 767px | 스마트폰 |
| Tablet | 768px ~ 1023px | 태블릿 |
| Desktop | 1024px ~ 1439px | 데스크톱 |
| Wide | 1440px~ | 대형 모니터 |

## 2. 레이아웃 전략
- **접근법**: Mobile-First / Desktop-First (선택)
- **그리드**: 12컬럼 기반
- **최대 너비**: 1200px (컨텐츠 영역)

## 3. 컴포넌트별 반응형 동작
| 컴포넌트 | Mobile | Tablet | Desktop |
|---------|--------|--------|---------|
| Navigation | 햄버거 | 축소 | 전체 |
| Sidebar | 숨김 | 오버레이 | 고정 |
| Grid | 1열 | 2열 | 3~4열 |
| Table | 카드형 | 스크롤 | 전체 |

## 4. 이미지 & 미디어 반응형
- `srcset` + `sizes` 사용 (해상도별 이미지)
- 비디오: 16:9 비율 유지, `max-width: 100%`
- 아이콘: SVG 사용 (벡터, 해상도 무관)

## 5. 터치 vs 마우스 인터랙션
| 동작 | 터치 (모바일) | 마우스 (데스크톱) |
|------|-------------|----------------|
| 클릭 | 탭 (최소 44x44px) | 클릭 |
| 호버 | 없음 (대체 UX 필요) | 호버 효과 |
| 스크롤 | 스와이프 | 스크롤 |
| 드래그 | 롱 프레스 + 드래그 | 클릭 + 드래그 |
