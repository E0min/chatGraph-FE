# 접근성 가이드 (Accessibility Guide)

<!-- 담당 에이전트: designer -->
<!-- 참조: WCAG 2.1 https://www.w3.org/TR/WCAG21/ -->

## 1. WCAG 2.1 준수 레벨 목표
- **목표 레벨**: AA
- **AAA 권장 항목**: 색상 대비 7:1, 확장된 자막

## 2. 색상 대비 기준
- **일반 텍스트**: 최소 4.5:1 (AA)
- **대형 텍스트 (18px+ bold, 24px+ regular)**: 최소 3:1
- **UI 컴포넌트 & 그래픽**: 최소 3:1
- **검증 도구**: axe DevTools, Lighthouse, Colour Contrast Analyser

## 3. 키보드 네비게이션
- 모든 인터랙티브 요소는 **Tab 키**로 접근 가능
- **논리적 탭 순서** 유지 (시각적 순서와 일치)
- **Skip Navigation** 링크 제공
- 모달/다이얼로그의 **포커스 트랩** 구현
- **Esc 키**로 팝업/드롭다운 닫기

## 4. 스크린 리더 지원 (ARIA)
- 모든 이미지에 `alt` 텍스트 (장식 이미지는 `alt=""`)
- 폼 요소에 `<label>` 연결 또는 `aria-label`
- 동적 콘텐츠에 `aria-live` 영역
- 커스텀 위젯에 적절한 `role` 속성
- 상태 변화 시 `aria-expanded`, `aria-selected` 갱신

## 5. 포커스 관리
- **가시적 포커스 인디케이터**: 최소 2px outline
- 페이지 전환 시 포커스 위치 관리
- 동적 콘텐츠 추가 시 포커스 이동 정책

## 6. 대체 텍스트 규칙
- **정보성 이미지**: 내용을 설명하는 alt 텍스트
- **기능성 이미지 (버튼/링크)**: 동작을 설명 (`alt="검색"`)
- **장식성 이미지**: `alt=""` + `aria-hidden="true"`
- **복잡한 이미지 (차트/그래프)**: `aria-describedby`로 상세 설명 연결

## 7. 폼 접근성 체크리스트
- [ ] 모든 입력 필드에 `<label>` 연결
- [ ] 필수 필드에 `aria-required="true"`
- [ ] 에러 메시지가 해당 필드와 연결 (`aria-describedby`)
- [ ] 에러 발생 시 포커스가 첫 번째 에러 필드로 이동
- [ ] 자동 완성 (`autocomplete`) 속성 적용
