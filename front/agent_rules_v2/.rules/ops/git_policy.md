# 🐙 Git Operations Policy (Template)

## 1. Commit Message Convention
Format: `type: message`

- `feat`: New feature
- `fix`: Bug fix
- `docs`: Documentation
- `chore`: Maintenance
- `refactor`: Code restructuring

## 2. Process
- **Small Commits**: 1 Logical Change = 1 Commit.
- **Reference**: Include Issue ID if available (e.g., `#123`).

## 3. Pull Request (PR)
- **Title**: Same as commit message.
- **Body**: meaningful description of *why* the change was made.
